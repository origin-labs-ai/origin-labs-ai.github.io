data-component="Headline" id="model-context-protocol"><strong>Model Context Protocol</strong></h2><p class="PA4F1q_reading-column post-text">One year ago, we <a href="/news/model-context-protocol">introduced</a> MCP as a universal, open standard for connecting AI applications to external systems. Since then, MCP has achieved incredible adoption:</p><ul class="PA4F1q_reading-column text-body-1-serif post-text"><li>Across the ecosystem: There are now more than 10,000 active public MCP servers, covering everything from developer tools to Fortune 500 deployments;</li><li>Across platforms: MCP has been adopted by ChatGPT, Cursor, Gemini, Microsoft Copilot, Visual Studio Code, and other popular AI products;</li><li>Across infrastructure: Enterprise-grade infrastructure now exists with deployment support for MCP from providers including AWS, Cloudflare, Google Cloud, and Microsoft Azure.</li></ul><div class="PA4F1q_media-column" data-type="image" data-width="full-width"><figure class="Duq99q_e-imageWithCaption"><img alt="Significant Milestone in MCP's first year" loading="lazy" width="1920" height="2500" decoding="async" data-nimg="1" style="color:transparent" src="https://origin-ten-jet.vercel.app/sites/anthropic/pages-assets/9c14d197bd9d1a61502e.webp"></figure></div><p class="PA4F1q_reading-column post-text"><br><br>We’re continuing to invest in MCP’s growth. Claude now has a directory with over 75 <a id="base-ui-_R_7j6drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://claude.com/connectors">connectors</a> (powered by MCP), and we recently launched <a href="/engineering/advanced-tool-use">Tool Search and Programmatic Tool Calling</a> capabilities in our API to help optimize production-scale MCP deployments, handling thousands of tools efficiently and reducing latency in complex agent workflows.<br><br>MCP now has an official, community-driven <a id="base-ui-_R_7n6drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://github.com/modelcontextprotocol/registry">Registry</a> for discovering available MCP servers, and the <a id="base-ui-_R_7o6drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://blog.modelcontextprotocol.io/posts/2025-11-25-first-mcp-anniversary/">November 25th</a> spec release introduced many new features, including asynchronous operations, statelessness, server identity, and official extensions. There are also official SDKs (Software Development Kits) for MCP in all major programming languages with 97M+ monthly SDK downloads across Python and TypeScript. <br><br>Since its inception, we’ve been committed to ensuring MCP remains open-source, community-driven and vendor-neutral. Today, we further that commitment by donating MCP to the Linux Foundation.</p><h2 class="tOQyXa_headline-4 PA4F1q_reading-column post-heading" data-component="Headline" id="the-linux-foundation-and-the-agentic-ai-foundation"><strong>The Linux Foundation and the Agentic AI Foundation</strong></h2><p class="PA4F1q_reading-column post-text">The <a id="base-ui-_R_1t8drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://www.linuxfoundation.org/">Linux Foundation</a> is a non-profit organization dedicated to fostering the growth of sustainable, open-source ecosystems through neutral stewardship, community building, and shared infrastructure. It has decades of experience stewarding the most critical and globally-significant open-source projects, including The Linux Kernel, Kubernetes, Node.js, and PyTorch. Importantly, the Linux Foundation has a proven track record in facilitating open collaboration and maintaining vendor neutrality.<br></p><p class="PA4F1q_reading-column post-text">The Agentic AI Foundation (AAIF) is a directed fund under the Linux Foundation co-founded by Anthropic, <a id="base-ui-_R_3p9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://block.xyz/">Block</a> and <a id="base-ui-_R_3q9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://openai.com/">OpenAI</a>, with support from <a id="base-ui-_R_3r9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://www.google.com/">Google</a><u class="PA4F1q_underline">, </u><a id="base-ui-_R_3s9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="http://microsoft.com">Microsoft</a>, <a id="base-ui-_R_3t9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://aws.amazon.com/">AWS</a>, <a id="base-ui-_R_3u9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://www.cloudflare.com/">Cloudflare</a> and <a id="base-ui-_R_3v9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://www.bloomberg.com/">Bloomberg</a>. The AAIF aims to ensure agentic AI evolves transparently, collaboratively, and in the public interest through strategic investment, community building, and shared development of open standards.</p><h2 class="tOQyXa_headline-4 PA4F1q_reading-column post-heading" data-component="Headline" id="donating-the-model-context-protocol"><strong>Donating the Model Context Protocol</strong></h2><p class="PA4F1q_reading-column post-text">Anthropic is donating the Model Context Protocol to the Linux Foundation's new Agentic AI Foundation, where it will join <a id="base-ui-_R_3pbdrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://github.com/block/goose">goose</a> by Block and <a id="base-ui-_R_3qbdrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="http://agents.md">AGENTS.md</a> by OpenAI as founding projects. Bringing these and future projects under the AAIF will foster innovation across the agentic AI ecosystem and ensure these foundational technologies remain neutral, open, and community-driven. <br><br>The Model Context Protocol’s <a id="base-ui-_R_3tbdrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://modelcontextprotocol.io/community/governance">governance model</a> will remain unchanged: the project’s maintainers will continue to prioritize community input and transparent decision-making.</p><h2 class="tOQyXa_headline-4 PA4F1q_reading-column post-heading" data-component="Headline" id="the-future-of-mcp"><strong>The future of MCP</strong></h2><p class="PA4F1q_reading-column post-text">Open-source software is essential for building a secure and innovative ecosystem for agentic AI. Today’s donation to the Linux Foundation demonstrates our commitment to ensuring MCP remains a neutral, open standard. We’re excited to continue contributing to MCP and other agentic AI projects through the AAIF.<br><br>Learn more about MCP at <a id="base-ui-_R_3rddrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://modelcontextprotocol.io">modelcontextprotocol.io</a> and get involved with the AAIF <a id="base-ui-_R_3sddrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://aaif.io/">here</a>.</p></div></div></article></div><!--$--><!--/$-->b:X
