It plans more carefully, sustains agentic tasks for longer, can operate more reliably in larger codebases, and has better code review and debugging skills to catch its own mistakes. And, in a first for our Opus-class models, Opus 4.6 features a 1M token context window in beta<sup class="caption PA4F1q_sup PA4F1q_footnote-marker"><a href="#footnote-1" id="footnote-ref-1" class="PA4F1q_footnote-ref" role="doc-noteref" aria-label="Footnote 1">1</a></sup>.</p><p class="PA4F1q_reading-column post-text">Opus 4.6 can also apply its improved abilities to a range of everyday work tasks: running financial analyses, doing research, and using and creating documents, spreadsheets, and presentations. Within <a id="base-ui-_R_3s3drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://claude.com/blog/cowork-research-preview" rel="noopener noreferrer">Cowork</a>, where Claude can multitask autonomously, Opus 4.6 can put all these skills to work on your behalf.</p><p class="PA4F1q_reading-column post-text">The model’s performance is state-of-the-art on several evaluations. For example, it achieves the highest score on the agentic coding evaluation <a id="base-ui-_R_f44drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://www.tbench.ai/news/announcement-2-0" rel="noopener noreferrer">Terminal-Bench 2.0</a> and leads all other frontier models on <a id="base-ui-_R_f84drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://agi.safe.ai/" rel="noopener noreferrer">Humanity’s Last Exam</a>, a complex multidisciplinary reasoning test. On <a id="base-ui-_R_fc4drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://artificialanalysis.ai/evaluations/gdpval-aa" rel="noopener noreferrer">GDPval-AA</a>—an evaluation of performance on economically valuable knowledge work tasks in finance, legal, and other domains<sup class="caption PA4F1q_sup PA4F1q_footnote-marker"><a href="#footnote-2" id="footnote-ref-2" class="PA4F1q_footnote-ref" role="doc-noteref" aria-label="Footnote 2">2</a></sup>—Opus 4.6 outperforms the industry’s next-best model (OpenAI’s GPT-5.2) by around 144 Elo points,<sup class="caption PA4F1q_sup PA4F1q_footnote-marker"><a href="#footnote-3" id="footnote-ref-3" class="PA4F1q_footnote-ref" role="doc-noteref" aria-label="Footnote 3">3</a></sup> and its own predecessor (Claude Opus 4.5) by 190 points. Opus 4.6 also performs better than any other model on <a id="base-ui-_R_fo4drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://openai.com/index/browsecomp/" rel="noopener
