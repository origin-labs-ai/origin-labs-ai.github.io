starting on Slack, which Claude can join as a team member. Grant Claude access to selected channels, and connect it to whichever tools, data—and even codebases—you choose. Then, anyone in the channel can tag <strong>@Claude</strong> in, and delegate tasks to it while they focus on other work. Claude builds context by remembering relevant information from the channels it’s in, and can plan out tasks to complete in the future.</p><p class="PA4F1q_reading-column post-text">We see Claude Tag as the beginning of an evolution of Claude Code: it makes the model even more proactive, and it works better with a full team. Tagging <strong>@Claude</strong> is now one of the main ways we get things done at Anthropic. Today, 65% of our product team’s code is created by our internal version of Claude Tag. The same pattern is now spreading well beyond engineering—we’re tagging Claude to chase down product metrics and data, work through support tickets, or even help find the root cause of tricky bugs.</p><div class="PA4F1q_media-column" data-type="video" data-width="full-width"><div class="qJNyFq_post-wrapper"><figure class="qJNyFq_post-video-container"><div class="TSxPAa_e-videoEmbed"><div class="_BfwWW_cover"><img alt="Video thumbnail" loading="lazy" width="1920" height="1080" decoding="async" data-nimg="1" style="color:transparent" src="https://origin-ten-jet.vercel.app/sites/anthropic/pages-assets/6a4f4ac09ea5e12a7a5b.webp"><button aria-label="Play video" data-component="Button" data-variant="tertiary" class="f9ZZrG_button f9ZZrG_corner-small f9ZZrG_variant-tertiary f9ZZrG_size-large f9ZZrG_icon-format-icon-only _BfwWW_playButton"><span class="f9ZZrG_icon"><svg class="lqbdHG_icon" width="18" height="18" viewBox="0 0 18 18"><path d="M3.59961 3.6418C3.59986 2.58403 4.76149 1.93696 5.66066 2.49394L14.303 7.85268C15.1543 8.38061 15.1542 9.61864 14.303 10.1466L5.66066 15.5054C4.8175 16.0278 3.74356 15.4919 3.61279 14.5509L3.59961 14.3575V3.6418ZM5.18692 3.25947C4.88726 3.07384 4.49987 3.28934 4.49962 3.6418V14.3575L4.50401 14.4226C4.54786 14.736 4.90598 14.914 5.18692 14.7399L13.8284 9.38199C14.1121 9.20596 14.1122 8.79328 13.8284 8.61734L5.18692 3.25947Z" fill="currentColor"></path></svg></span></button></div></div></figure></div></div><p class="PA4F1q_reading-column post-text">We’re launching <a id="base-ui-_R_1u5drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://www.claude.com/product/tag" rel="noopener noreferrer">Claude Tag on Slack</a>, since it’s a natural home for collaborative work between teams and AI, and where much of Anthropic’s day-to-day work already happens. It’s available today in beta for Claude Enterprise and Team customers. Our goal is to expand where it’s available more widely, so that teams can tag @Claude in the many other places they work.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="working-with-claude">Working with @Claude</h3><p class="PA4F1q_reading-column post-text">If you’ve worked with Claude Code or Cowork before, Claude Tag will feel familiar. Tag @Claude with a request in simple terms and it’ll break its task down into stages and then work through them in turn, using the tools it has access to. Once it’s done, it’ll respond in a Slack thread with what it’s created.</p><p class="PA4F1q_reading-column post-text">But tagging Claude comes with a few new advantages:</p><p class="PA4F1q_reading-column post-text"><strong>@Claude is multiplayer.</strong> Within a given Slack channel, there’s one Claude that interacts with everyone. This means that anyone can see what it’s working on, and can pick up the conversation from where the last person left off. This makes tagging Claude very different from working within a single chat or for a single task—it’s much more like interacting collaboratively with a teammate.</p><p class="PA4F1q_reading-column post-text"><strong>@Claude learns over time. </strong>As Claude follows along with its channel, it builds more context about the work. This means that users don’t need to explain things to it from scratch over and over again. And Claude can even automatically learn from <em>other</em> Slack channels and data sources, if it’s granted permission. (It doesn’t report from private channels.) This gives it the tacit knowledge necessary for it to provide the best possible work.</p><p class="PA4F1q_reading-column post-text"><strong>@Claude takes initiative.</strong> If “ambient” behavior is enabled, Claude will proactively keep you updated about whatever it thinks you might need to know. It’ll flag relevant information from across the channels it’s in and the tools it’s connected to, and follow up on threads or tasks that have gone quiet without being resolved.</p><p class="PA4F1q_reading-column post-text"><strong>@Claude works asynchronously.</strong> Set Claude a task, and you can focus on your other priorities while it works. It can also schedule tasks for itself, pursuing a project autonomously over hours or days. We’ve found this particularly helpful at Anthropic: we now spend much more of our time delegating tasks to many Claudes in parallel.</p><p class="PA4F1q_reading-column post-text">You can also send Claude direct messages: it’ll respond privately, using the personal tools and connectors you’ve set up.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="getting-started">Getting started</h3><p class="PA4F1q_reading-column post-text">We’ve designed Claude Tag with teams and organizations in mind: @Claude’s access to sensitive data and task-specific tools can be very tightly controlled.</p><p class="PA4F1q_reading-column post-text">To get up and running, system administrators specify which tools and information the model should have access to, in which channels. Think of it as creating separate Claude identities for different uses: everything, including its memories, will stay scoped to the channels defined by the administrators. For example, a model set up for sales work won’t pass on memories to one set up for engineering; nor will it give engineers access to any sales data or tools. More information about provisioning access is <a id="base-ui-_R_1ugdrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://claude.com/blog/agent-identity-access-model" rel="noopener noreferrer">available here</a>.</p><p class="PA4F1q_reading-column post-text">Once permissions are set, everyone can begin tagging right away. Administrators can set limits for token spend (both for the organization and for individual channels), and can view a log of everything that @Claude has done, along with who requested each task.</p><p class="PA4F1q_reading-column post-text">If you’re a Claude Enterprise or Team customer, you have access to Claude Tag in beta starting today.
