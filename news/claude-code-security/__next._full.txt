data-theme="ivory"><p class="PA4F1q_reading-column post-text"><strong>Claude Code Security</strong>, a new capability built into Claude Code on the web, is now available in a limited research preview. It scans codebases for security vulnerabilities and suggests targeted software patches for human review, allowing teams to find and fix security issues that traditional methods often miss.</p><p class="PA4F1q_reading-column post-text">Security teams face a common challenge: too many software vulnerabilities and not enough people to address them. Existing analysis tools help, but only to a point, as they usually look for known patterns. Finding the subtle, context-dependent vulnerabilities that are often exploited by attackers requires skilled human researchers, who are dealing with ever-expanding backlogs.</p><p class="PA4F1q_reading-column post-text">AI is beginning to change that calculus. We’ve recently shown that <a id="base-ui-_R_1u3drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://red.anthropic.com/2026/zero-days/" rel="noopener noreferrer">Claude can detect novel, high-severity vulnerabilities</a>. But the same capabilities that help defenders find and fix vulnerabilities could help attackers exploit them.</p><p class="PA4F1q_reading-column post-text">Claude Code Security is intended to put this power squarely in the hands of defenders and protect code against this new category of AI-enabled attack. We’re releasing it as a limited research preview to Enterprise and Team customers, with expedited access for maintainers of open-source repositories, so we can work together to refine its capabilities and ensure it is deployed responsibly.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="how-claude-code-security-works">How Claude Code Security works</h3><div class="PA4F1q_media-column" data-type="video" data-width="inline-width"><div class="qJNyFq_post-wrapper"><figure class="qJNyFq_post-video-container"><div class="TSxPAa_e-videoEmbed"><div class="_BfwWW_cover"><img alt="Video thumbnail" loading="lazy" width="1280" height="720" decoding="async" data-nimg="1" style="color:transparent" src="https://origin-ten-jet.vercel.app/sites/anthropic/pages-assets/cdcb51642cdc6bb47cd6.jpg"><button aria-label="Play video" data-component="Button" data-variant="tertiary" class="f9ZZrG_button f9ZZrG_corner-small f9ZZrG_variant-tertiary f9ZZrG_size-large f9ZZrG_icon-format-icon-only _BfwWW_playButton"><span class="f9ZZrG_icon"><svg class="lqbdHG_icon" width="18" height="18" viewBox="0 0 18 18"><path d="M3.59961 3.6418C3.59986 2.58403 4.76149 1.93696 5.66066 2.49394L14.303 7.85268C15.1543 8.38061 15.1542 9.61864 14.303 10.1466L5.66066 15.5054C4.8175 16.0278 3.74356 15.4919 3.61279 14.5509L3.59961 14.3575V3.6418ZM5.18692 3.25947C4.88726 3.07384 4.49987 3.28934 4.49962 3.6418V14.3575L4.50401 14.4226C4.54786 14.736 4.90598 14.914 5.18692 14.7399L13.8284 9.38199C14.1121 9.20596 14.1122 8.79328 13.8284 8.61734L5.18692 3.25947Z" fill="currentColor"></path></svg></span></button></div></div></figure></div></div><p class="PA4F1q_reading-column post-text">Static analysis—a widely deployed form of automated security testing—is typically rule-based, meaning it matches code against known vulnerability patterns. That catches common issues, like exposed passwords or outdated encryption, but often misses more complex vulnerabilities, like flaws in business logic or broken access control.</p><p class="PA4F1q_reading-column post-text">Rather than scanning for known patterns, Claude Code Security reads and reasons about your code the way a human security researcher would: understanding how components interact, tracing how data moves through your application, and catching complex vulnerabilities that rule-based tools miss.</p><p class="PA4F1q_reading-column post-text">Every finding goes through a multi-stage verification process before it reaches an analyst. Claude re-examines each result, attempting to prove or disprove its own findings and filter out false positives. Findings are also assigned severity ratings so teams can focus on the most important fixes first.</p><p class="PA4F1q_reading-column post-text">Validated findings appear in the Claude Code Security dashboard, where teams can review them, inspect the suggested patches, and approve fixes. Because these issues often involve nuances that are difficult to assess from source code alone, Claude also provides a confidence rating for each finding. Nothing is applied without human approval: Claude Code Security identifies problems and suggests solutions, but developers always make the call.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="using-claude-for-cybersecurity">Using Claude for cybersecurity</h3><p class="PA4F1q_reading-column post-text">Claude Code Security builds on more than a year of research into Claude’s cybersecurity capabilities. Our Frontier Red Team has been stress-testing these abilities systematically: entering Claude in <a id="base-ui-_R_3qcdrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://red.anthropic.com/2025/ai-for-cyber-defenders/" rel="noopener noreferrer">competitive Capture-the-Flag events</a>, partnering with Pacific Northwest National Laboratory to <a id="base-ui-_R_3scdrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://red.anthropic.com/2026/critical-infrastructure-defense/" rel="noopener noreferrer">experiment with using AI to defend critical infrastructure</a>, and refining Claude’s ability to find and patch real vulnerabilities in code.</p><p class="PA4F1q_reading-column post-text">Claude’s cyberdefensive abilities have improved substantially as a result. Using <a target="_blank" href="/news/claude-opus-4-6" rel="noopener noreferrer">Claude Opus 4.6</a>, released earlier this month, our team <a id="base-ui-_R_3sddrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://red.anthropic.com/2026/zero-days/" rel="noopener noreferrer">found over 500 vulnerabilities</a> in production open-source codebases—bugs that had gone undetected for decades, despite years of expert review. We’re working through triage and responsible disclosure with maintainers now, and we plan to expand our security work with the open-source community.</p><p class="PA4F1q_reading-column post-text">We also use Claude to review our own code, and we’ve found it to be extremely effective at securing Anthropic’s systems. We built Claude Code Security to make those same defensive capabilities more widely available. And since it’s built on Claude Code, teams can review findings and iterate on fixes within the tools they already use.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="the-road-ahead">The road ahead</h3><p class="PA4F1q_reading-column post-text">This is a pivotal time for cybersecurity. We expect that a significant share of the world’s code will be scanned by AI in the near future, given how effective models have become at finding long-hidden bugs and security issues.</p><p class="PA4F1q_reading-column post-text">Attackers will use AI to find exploitable weaknesses faster than ever. But defenders who move quickly can find those same weaknesses, patch them, and reduce the risk of an attack. Claude Code Security is one step towards our goal of more secure codebases and a higher security baseline across the industry.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="getting-started">Getting started</h3><p class="PA4F1q_reading-column post-text">We’re opening a limited research preview of Claude Code Security to Enterprise and Team customers today.
