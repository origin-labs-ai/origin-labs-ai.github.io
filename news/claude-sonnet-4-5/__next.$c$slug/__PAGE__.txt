And it shows substantial gains in reasoning and math.</p><p class="PA4F1q_reading-column post-text">Code is everywhere. It runs every application, spreadsheet, and software tool you use. Being able to use those tools and reason through hard problems is how modern work gets done.</p><p class="PA4F1q_reading-column post-text">Claude Sonnet 4.5 makes this possible. We're releasing it along with a set of major upgrades to our products. In <a target="_blank" href="/news/enabling-claude-code-to-work-more-autonomously" rel="noopener noreferrer">Claude Code</a>, we've added checkpoints—one of our most requested features—that save your progress and allow you to roll back instantly to a previous state. In the Claude <a id="base-ui-_R_fg3drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://claude.ai/download" rel="noopener noreferrer">apps</a>, we've brought code execution and <a target="_blank" href="/news/create-files" rel="noopener noreferrer">file creation</a> (spreadsheets, slides, and documents) directly into the conversation. And we've made the <a target="_blank" href="/news/claude-for-chrome" rel="noopener noreferrer">Claude for Chrome</a> extension available to Max users who joined the waitlist last month.</p><p class="PA4F1q_reading-column post-text">We're also giving developers the building blocks we use ourselves to make Claude Code. The infrastructure that powers our frontier products—and allows them to reach their full potential—is now yours to build with.</p><p class="PA4F1q_reading-column post-text">This is the <a target="_blank" href="/claude-sonnet-4-5-system-card" rel="noopener noreferrer">most aligned frontier model</a> we’ve ever released, showing large improvements across several areas of alignment compared to previous Claude models.</p><p class="PA4F1q_reading-column post-text">Claude Sonnet 4.5 is available everywhere today. We report 77.2%, which was averaged over 10 trials, no test-time compute, and 200K thinking budget on the full 500-problem SWE-bench Verified dataset.<ul class="PA4F1q_reading-column text-body-1-serif post-text"><li>The score reported uses a minor prompt addition: "You should use tools as much as possible, ideally more than 100 times. A prompt addendum was also added to the Telecom User prompt to avoid failure modes from the user ending the interaction incorrectly.</li><li><strong>AIME</strong>: Sonnet 4.5 score reported using sampling at temperature 1.0. The model used 64K reasoning tokens for the Python configuration.</li><li><strong>OSWorld: </strong>All scores reported use the official OSWorld-Verified framework with 100 max steps, averaged across 4 runs.</li><li><strong>MMMLU</strong>: All scores reported are the average of 5 runs over 14 non-English languages with extended thinking (up to 128K).</li><li><strong>Finance Agent</strong>: All scores reported were run and published by <a id="base-ui-_R_3rf7drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" target="_blank" href="https://vals.ai" rel="noopener noreferrer">Vals AI</a> on their public leaderboard.
