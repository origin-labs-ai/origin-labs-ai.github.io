donating <a id="base-ui-_R_v1drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://agentskills.io/home">Agent Skills</a>, the open standard that gives AI agents specialized knowledge and workflows, to the Agentic AI Foundation (AAIF). More than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, have integrated Agent Skills since we published the standard in December 2025.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="agent-interoperability-through-simplicity">Agent interoperability through simplicity</h3><p class="PA4F1q_reading-column post-text">A skill is a folder containing a SKILL.md file that teaches an agent a specific task or domain, along with any scripts or reference material it needs. We developed skills while working on Claude Code. It handled general knowledge work well, but often lacked the procedural knowledge that real business tasks need. Within weeks of our October 2025 launch, developers published thousands of skills on GitHub and wrote loaders for Codex, Cursor, and OpenCode. We then published Agent Skills as an open standard, under its own GitHub organization and domain, so any agent could use it. So far, 1 million skills have been published and nearly 280 million installed.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="donating-agent-skills-to-aaif">Donating Agent Skills to AAIF</h3><p class="PA4F1q_reading-column post-text">We’re committed to keeping Agent Skills open, community-driven, and vendor-neutral. Today, we are donating the standard to the Agentic AI Foundation (AAIF) under the Linux Foundation, <a href="/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation">which we co-founded</a> with Block and OpenAI last year, and to which we donated the Model Context Protocol (MCP). The AAIF will provide a neutral home to the standard going forward, ensuring the community has a say in where Agent Skills go next.</p><p class="PA4F1q_reading-column post-text">We are donating the Agent Skills name and logo, the GitHub organization, and the <a id="base-ui-_R_v6drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://agentskills.io/home">agentskills.io</a> domain. You can continue to use the standard or contribute to it without joining the AAIF.</p><p class="PA4F1q_reading-column post-text">Engineers from Anthropic, Google, OpenAI, and other companies will maintain the standard as individuals, with David Soria Parra and Mahesh Murag as Lead Maintainers.</p><h3 class="tOQyXa_headline-5 PA4F1q_reading-column post-section" data-component="Headline" id="what-comes-next">What comes next</h3><p class="PA4F1q_reading-column post-text">We’ve proposed starting with a roadmap covering versioned releases, a formal proposal process, and security guidance for people who write and install skills. As with MCP, the project will continue to prioritize community input and transparent decision-making. You can join the project’s <a id="base-ui-_R_v9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://discord.gg/MKPE9g8aUy">Discord</a> to give feedback on proposed specification changes.</p><p class="PA4F1q_reading-column post-text">Thank you to the developers who built with Agent Skills from the start, and to the teams who brought skills into their products. Read the specification at <a id="base-ui-_R_1tadrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://agentskills.io">agentskills.io</a> and join the discussion on <a id="base-ui-_R_1uadrpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://github.com/agentskills/agentskills">GitHub</a>.</p></div></div></article></div><!--$--><!--/$-->b:X
