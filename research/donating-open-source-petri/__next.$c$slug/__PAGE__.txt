href="/research/petri-open-source-auditing">Petri</a>, an open-source toolbox of alignment tests that can be applied to any large language model. Petri, which was developed as part of our Anthropic Fellows program, can be used to rapidly and easily test AI models for concerning tendencies like deception, sycophancy, and cooperation with harmful requests. It’s part of our efforts to develop alignment tools that are open and useful for the whole AI development community.</p><p class="PA4F1q_reading-column post-text">Petri has been part of our alignment assessment for every Claude model since Claude Sonnet 4.5. It compares how the new model behaves across a range of alignment-relevant scenarios that are simulated by a separate “auditor” model. A further “judge” model then scores the resulting transcripts for misaligned behaviors.</p><p class="PA4F1q_reading-column post-text">We’ve been pleased to see Petri being used by external organizations: for example, the UK’s AI Security Institute (AISI) made it a <a id="base-ui-_R_v3drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://arxiv.org/abs/2604.00788">major part</a> of how they evaluate models for their propensity to sabotage AI research.</p><p class="PA4F1q_reading-column post-text">We’re now updating Petri to its third version. Here are some of the biggest changes:</p><ul class="PA4F1q_reading-column text-body-1-serif post-text"><li><em>Adaptability. </em>Petri 3.0 involves major architectural changes that allow users to adapt it to more uses, in particular by splitting the auditor model and the target model into separate components that can be tweaked separately;</li><li><em>Realism.</em> Despite the fact that alignment researchers try to make tests appear realistic, a model can often deduce from various artificialities in the setup that it’s actually part of a test. And if the model is aware it’s being evaluated, the researcher is no longer able to see how the model behaves <em>in general</em>. An add-on to Petri, which we’re calling “Dish,” makes the setup far more realistic, for example by running the tests using the model’s real system prompt and the real “scaffold” (the software that wraps around the model to help it meet its goals) that would be used in genuine model deployments;</li><li><em>Depth</em>. We’ve now integrated Petri with our other open-source alignment tool, <a href="/research/bloom">Bloom</a>, which can perform much more in-depth assessments of specific chosen behaviors (in comparison to Petri’s wider-ranging approach).</li></ul><p class="PA4F1q_reading-column post-text">We’re also giving Petri a new home. We have handed over its development to <a id="base-ui-_R_1t6drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://meridianlabs.ai/">Meridian Labs</a>, an AI evaluation nonprofit. This move—similar to when we <a href="/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation">donated</a> the Model Context Protocol (MCP) to the Linux Foundation—will help ensure that Petri remains independent of any AI lab, so that its results will be seen as neutral and credible by those across the industry and beyond.</p><p class="PA4F1q_reading-column post-text">As part of Meridian Labs, Petri joins other tools like <a id="base-ui-_R_1t7drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://inspect.aisi.org.uk/">Inspect</a> and <a id="base-ui-_R_1u7drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://meridianlabs-ai.github.io/inspect_scout/">Scout</a>, building a technology stack that is open to labs, independent researchers, and governments alike, at a time when reliable tests of AI model behavior matter more than ever.</p><p class="PA4F1q_reading-column post-text">You can read more about Petri 3.0 on <a id="base-ui-_R_v8drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://meridianlabs.ai/blog/posts/introducing-petri-3/">the Meridian Labs blog</a>.</p><p class="PA4F1q_reading-column post-text">Instructions to install and use Petri can be found on the <a id="base-ui-_R_v9drpbsnpfkq6btb_" data-base-ui-tooltip-trigger="" href="https://meridianlabs-ai.github.io/inspect_petri/">Petri website</a>.</p></div></div></article></div><!--$--><!--/$-->b:X
